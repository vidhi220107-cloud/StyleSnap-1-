# 👗 StyleSnap AI

### AI-powered fashion companion for wardrobe management, outfit styling, fashion product classification, and smart shopping.

🚀 **Live Project:** 👉 https://stylesnap.streamlit.app/

---

## 📌 About the Project

**StyleSnap AI** is an AI-powered fashion application designed to help users manage their wardrobe, discover outfit ideas, analyze fashion products, and get personalized styling assistance.

The application combines **Computer Vision, Deep Learning, Machine Learning, and Streamlit** to provide an interactive fashion experience.

Users can add clothing items to their digital wardrobe, view their wardrobe collection, explore AI-based styling features, analyze wardrobe information, and use smart shopping and camera-based styling features.

The project is developed as a team project with multiple modules integrated into a single Streamlit application.

---

## 🎯 Objectives

The main objectives of StyleSnap AI are:

- 👗 Create a digital wardrobe for storing clothing items.
- 🤖 Provide AI-powered fashion and styling assistance.
- 📸 Use camera/image-based features for fashion analysis.
- 🛍️ Provide smart shopping-related functionality.
- 📊 Analyze wardrobe data using visualizations.
- 🧠 Apply Machine Learning and Deep Learning concepts to fashion-related tasks.
- 💻 Provide all features through an easy-to-use Streamlit web application.

---

## ✨ Key Features

### 👚 1. Add to Wardrobe

Users can add clothing items to their digital wardrobe.

Features include:

- Upload clothing images.
- Store clothing items in the wardrobe.
- Organize fashion items digitally.
- Maintain wardrobe information for later use.

---

### 👗 2. My Wardrobe

The **My Wardrobe** section allows users to view and manage their saved clothing collection.

Users can:

- View uploaded wardrobe items.
- Browse their clothing collection.
- Access stored wardrobe information.
- Manage their digital wardrobe.

---

### 🤖 3. AI Stylist

The **AI Stylist** module provides AI-based styling assistance.

It is designed to help users explore outfit combinations and make use of their existing wardrobe items for styling.

The module integrates AI-based functionality into the fashion recommendation workflow.

---

### 📊 4. Analytics

The **Analytics** section provides insights into the user's wardrobe.

It uses data visualization to help understand wardrobe-related information through:

- Charts
- Graphs
- Wardrobe statistics
- Item distribution
- Data-based insights

---

### 🛍️ 5. Smart Shopping

The **Smart Shopping** module provides functionality related to fashion product exploration and shopping assistance.

It is designed to connect fashion preferences with product-related information and make the shopping process more organized.

---

### 📸 6. AI Camera Stylist

The **AI Camera Stylist** provides an image/camera-based fashion interaction feature.

Users can use an image input to interact with the AI-based styling functionality.

This module combines image processing and AI-based fashion analysis to create an interactive styling experience.

---
